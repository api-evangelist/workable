Workable's MCP Server expansion adds 37 new tools to its original set, now covering 94 capabilities across hiring and HR. The expanded server includes advanced candidate and employee search, a 15-tool performance review suite, member administration, and profile management, all available through AI assistants like Claude and ChatGPT. Most tools ship at no added cost on every plan; advanced search requires Premier+ or Enterprise.
